# Notion workflow

## Capture

Create or develop an entry in Daily Entries & Content. It must include a Core Truth and Story or Evidence before it becomes production-ready.

## Promote

Create one Content Production record. Select the primary pillar, content type, goal, and one test variable.

## Adapt a saved post

The 9 AM / 9 PM sync creates raw-save rows as `New`. The content engine then inspects the actual post, records delivery DNA, pairs it with verified Mario-owned material, and moves it to `Needs Review`.

Mario approves a pairing by changing the save to `Approved` or approving it in Codex. Only then may the engine create and link a Content Production record and mark the save `Used`.

## Generate

Use the repository skill to produce the creative package. Store the finished package in the page body and populate the corresponding properties.

## Produce

Move Status through Script Ready, Ready to Record, Recorded, Edited, Scheduled, and Posted. Post Date powers the publishing calendar.

## Measure

Enter metrics at a consistent review point. Do not compare a mature post with a newly published post.

## Learn

During weekly review:

1. Mark genuine outliers as Winner.
2. Explain why each winner likely worked in Performance Notes.
3. Update the Hook Swipe File when a reusable hook pattern emerged.
4. Write one batch-level learning to the repository ledger.
5. Select one test variable for the next batch.
