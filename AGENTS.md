# Repository instructions

This repository powers the personal brand at `@mario_polancojr`.

## Source hierarchy

1. `brand-knowledge/00_SOURCE_OF_TRUTH.md`
2. The remaining files in `brand-knowledge/`
3. The live Notion Content Operating System
4. Templates and implementation documentation

If instructions conflict, the higher source wins.

## Content rules

- Mario's lived experience, observations, and opinions are the only topic sources.
- Saved posts are format references only.
- Prefer a Mario-specific story plus a clear or aggressive opinion over generic self-improvement advice.
- Generate 3-5 spoken hooks and 2-3 on-screen hooks before writing the body.
- Assign one primary goal and one test variable to every content item.
- Do not invent stories, metrics, results, quotes, or biographical details.
- Instagram is primary. Repurposing is downstream.
- Daily posting is the floor. Twice daily is preferred only when strong inventory supports it.

## Engineering rules

- Never commit credentials, cookies, API keys, tokens, state files, or logs.
- Keep Notion property names aligned with `notion/SCHEMA.md`.
- Prefer manual, observable workflows before scheduling automation.
- Treat files under the source engine as read-only references. Do not modify them.
