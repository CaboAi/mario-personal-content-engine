# Content package contract

## Required header

```text
CONTENT: [working title]
FORMAT: [format]
PRIMARY PLATFORM: Instagram
REPURPOSE: [platforms or None]
PRIMARY GOAL: [one]
PRIMARY PILLAR: [one]
SECONDARY PILLAR: [optional]
SOURCE: [story-bank entry, Notion entry, or user-provided story]
TEST VARIABLE: [one]
HYPOTHESIS: [if/then/because statement]
```

## Hook block

```text
SPOKEN HOOK OPTIONS
1. ...
2. ...
3. ...
[4-5 when useful]

ON-SCREEN HOOK OPTIONS
1. ...
2. ...
[3 when useful]

SELECTED SPOKEN HOOK: ...
SELECTED ON-SCREEN HOOK: ...
WHY: [one sentence]
```

## Format bodies

### Yap Reel

- Personal tension, confession, disagreement, or receipt.
- One developed argument.
- A broader takeaway after the receipt.
- Strong closing line.
- Suggested visual or framing only when Visual is relevant.

### Mini Story

- Scene.
- Felt experience.
- Choice or turning point.
- What changed.
- One realization.

### POV / Realization

- One on-screen line.
- Optional short caption.
- Simple B-roll direction.
- No padded script.

### Carousel

- Cover hook.
- One job per slide.
- Repeating visual spine through the middle.
- Payoff.
- Final save/share line that does not weaken the ending.

### Written Post

- Opening line with tension.
- Personal receipt.
- Developed interpretation.
- Strong final thought.

### Long-form

- Central question or argument.
- Story spine.
- Developed sections.
- Counterpoint or complication.
- Resolution that remains honest about what is unfinished.

## Closing block

```text
CTA: ...
CAPTION: ...
PRODUCTION NOTES: ...
PRIVACY / FACT CHECK: ...
NOTION STATUS: Script Ready
```
