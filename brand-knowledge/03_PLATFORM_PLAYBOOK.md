# Platform playbook

This file stores operating rules, not folklore. Add time-sensitive platform claims only with a dated primary source and a review date.

## Instagram

- Primary platform and canonical version.
- Reels carry Yap, Mini Story, and POV / Realization formats.
- Carousels operate as visual essays rather than corporate decks.
- Track views or reach, average watch time when available, shares, saves, follows, and qualitative notes.
- Optimize the first seconds before adding length.

## TikTok

- Repurpose short-form when the spoken delivery remains natural.
- Recut the opening or on-screen text when the Instagram version depends on feed context.
- Do not assume the Instagram caption or CTA transfers unchanged.

## YouTube Shorts

- Repurpose when the idea resolves cleanly without profile context.
- Title for the actual tension, not vague inspiration.
- Keep the core spoken message stable when the current test variable is not platform.

## Threads

- Convert the core realization into a complete written thought.
- Preserve the opinion; do not paste a transcript with line breaks.
- Use the personal receipt when it fits within the post.
